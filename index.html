Human Machine Interface · Web Bluetooth Demo

XENSIV™ Maus Konfigurator

Konfiguration und Live-Analyse der XENSIV™ Maus direkt im Browser – LED, DPI, Tasten-Sensorik mit Schwellwerten sowie Kalibrierung des magnetischen Scrollrads. Die Kommunikation erfolgt über GATT (Web Bluetooth), identisch zum Desktop-Tool „XENSIV Mouse Control v1.1“.

Web Bluetooth · BLE GATT Live-Monitoring Zero Install
Keine XENSIV™ Maus verbunden

Koppeln Sie die XENSIV™ Maus zunächst in den Bluetooth-Einstellungen des Betriebssystems. Danach genügt einmalig die Freigabe im Browser – jeder weitere Aufruf dieser Seite erkennt die Maus automatisch. Voraussetzung ist ein Chromium-basierter Browser (Chrome, Edge, Opera) sowie ein Aufruf über HTTPS oder localhost.

GATT-Dienste & Diagnose

Web Bluetooth gibt ausschließlich Dienste frei, die vor dem Verbindungsaufbau angemeldet wurden. Tragen Sie hier die 128-Bit-UUID des XENSIV-Herstellerdienstes ein – eine UUID pro Zeile oder durch Komma getrennt. Die UUID lässt sich in Chrome über chrome://bluetooth-internals → Devices → Inspect auslesen. Der Standard-Batteriedienst (0x180F) ist bereits hinterlegt.
