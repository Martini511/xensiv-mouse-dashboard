Only one sensor measures per button: enabling one releases the one so far on the same side. The thresholds take effect in the device itself – if a threshold lies above the pressure the sensor actually reaches, the button stops triggering across the whole computer, even after this page is closed. The enable also decides which sensor live monitoring follows per button; it shows the values that can be reached.

If the mouse reports no enable at all when read – recognisable by an answer in which no byte lies above 127 –, what was last written to the device takes its place. That note stays in this browser, even after disconnecting and reloading. “Load” therefore discards unsaved changes. If nothing has ever been written, the assumption is that the force sensors measure. The thresholds come from the device in every case, and on writing the enable goes across in full.

04 Wheel calibrationOffsets, amplitudes and pressure threshold

The calibration run expects one full revolution of the wheel. The pressure threshold is shown a thousand times larger than the firmware keeps it – exactly as in the desktop tool. The live view shows the mark a hundred units lower: the mouse clicks that much earlier than the stored value suggests.
